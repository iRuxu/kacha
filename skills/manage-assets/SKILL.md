# 管理工作台资产

1. 从项目根目录的 `AGENTS.md` 找到对应资产库的约定，查看目标资产已有的 `index.json`、`README.md` 和当前引用。按所属库内的完整相对路径定位资产。
2. 将文件按所属资产库的目录和命名约定落盘，并更新索引。沿用已有条目的 ID 和字段。只有能与该文件版本核实对应的生成词才写入索引或引用生成记录。
3. 新生成的候选另存。用户确认采用后，再更新默认素材或现行条目。替换现行素材时，按项目约定归档上一版并登记历史。
4. 移动或改名后，检查当前索引、制作说明以及项目中引用该文件的分镜，更新对应路径。
